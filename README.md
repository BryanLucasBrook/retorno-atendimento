# Retorno de atendimento

Formulário para montar o retorno de atendimento: modelo para colar no SAP e mensagem pronta para o grupo do WhatsApp (envio direto ou por QR Code).

Acesse pelo navegador: https://bryanlucasbrook.github.io/retorno-atendimento/

Os dados preenchidos ficam salvos só no navegador de quem usa.
